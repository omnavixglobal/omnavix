How this prototype works

  1. The website loads data/OMNAVIX_Global_Corridor_Database_V1.xlsx.
  2. JavaScript reads the Corridor Database worksheet in the browser.
  3. Country/payment information is displayed dynamically.
  4. The currency module fetches a current reference rate when connected to the internet.
  5. You can update the Excel corridor records and replace the database file in the website folder; the protected registry remains as a safety floor.
Production recommendation: move the master data to a controlled database/API after the research prototype. Excel is excellent for the first MVP, but it should not remain the production system of record.
